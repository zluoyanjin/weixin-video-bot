# 微信视频号多账号自动发言机器人

一个给**不懂代码的人**用的微信视频号自动发言工具：每个视频号账号开一个独立的 Chrome 窗口登录，机器人按你设定的间隔，自动往直播间评论区发送预先写好的话术。

- 全程**双击 .bat 文件**即可使用，不需要碰任何代码
- 多个账号互不干扰，各自一个浏览器窗口、各自一个端口
- 登录态持久化，第一次登录好之后基本不用再登
- 图形化配置窗口：改账号、改端口、改话术、改间隔，一键启动/停止

> ⚠️ **使用前请务必阅读文末《合规与免责声明》**。自动化发言可能违反微信视频号平台规则，请仅用于你拥有或已获授权的账号，并自行承担相关风险。

---

## 一、功能特性

- **多账号支持**：一个账号 = 一个 Chrome 窗口 + 一个 CDP 端口（9222 / 9223 / 9224…），可同时挂多个视频号
- **全量发送**：每次到点，把你写的所有话术**按行依次全部发一遍**（也可切换为「每条轮流发一条」模式）
- **登录态持久化**：登录信息保存在 `chrome_profiles/`，不删就不会掉登录
- **断线重连**：浏览器断开会自动重连
- **演练模式**：只打印「模拟发送」、不真发，方便上线前核对账号/端口/间隔
- **自检 / 体检**：不依赖真实账号即可验证程序本身是否正常

---

## 二、工作原理

```
配置账号.bat
   └─> 弹出图形窗口（Tkinter）
          ├─ 启动 Chrome  ──> 每个账号开一个 Chrome（--remote-debugging-port + 独立 user-data-dir）
          │                   窗口上的绿底标签标明「账号名 · 端口 XXXX」，方便核对
          └─ 启动机器人 ──> Playwright connect_over_cdp 连上对应 Chrome
                             定时往直播间评论框填入话术并发送
```

技术栈：Python + [Playwright](https://playwright.dev/python/) + Chrome 远程调试（CDP）+ Tkinter 配置界面。

├─ 体检.bat          可选：真实账号体检，只连接不发送
├─ 打包成exe.bat     开发用，客户不需要

├─ config/
│   └─ accounts.json  ★ 所有配置都在这一个文件里

## 四、快速开始（客户版，只要两步）

### 第 1 步：安装环境（只做一次）
双击 `安装环境.bat`，等黑色窗口跑完（首次会下载 Playwright，需几分钟），看到「安装完成」按任意键关闭。

**前提**：
- 电脑已装 **Google Chrome**
- 已装 **Python 3.10+**，安装时务必勾选 **`Add Python.exe to PATH`**

### 第 2 步：配置账号 + 登录 + 开机器人（全在一个窗口里）
双击 `配置账号.bat`，会弹出一个图形窗口：

1. **填账号**：左侧选中一个账号，中间填写
   | 字段 | 说明 |
   |---|---|
   | 账号名称 | 任意，用于日志里区分 |
   | CDP 端口 | 每个账号唯一，不可重复（9222 / 9223 / 9224…） |
   | 发送间隔(秒) | 建议 **≥ 300**，太快易被平台限制 |
   | 启用 | 不勾则跳过该账号 |
   | 直播间地址 | 选填，填了机器人会自动打开该直播间 |
   | 每轮发全部话术 | 勾选（默认）：到点把文案框里**所有行依次全发完**；不勾：每条按间隔轮流发一条 |
   | 发送文案 | 一行一条；默认每轮全部依次发出 |

2. **点「启动 Chrome」**：依次弹出 Chrome 窗口，每个对应一个账号。**分别登录不同的视频号并进入要发言的直播间**（窗口上有绿底标签标明账号与端口）。

3. **点「启动机器人」**：按间隔自动发送，窗口下方「运行日志」实时显示发送情况。想停：点「停止机器人」或直接关窗口。

> 登录状态保存在 `chrome_profiles/`，第一次登录后基本无需重登。**切勿删除该文件夹，否则登录态丢失。**

更详细的图文步骤见 [`小白使用指南.md`](小白使用指南.md) 与 [`使用说明.md`](使用说明.md)。

## 五、常见配置场景

- **想多发几个视频号**：在配置窗口点「新增账号」，填名字 + 新端口（如 9225），保存后点「启动 Chrome」会多开一个窗口。
- **想改发什么话 / 多久发一次**：双击 `配置账号.bat` 改完点「保存配置」，下次启动机器人即生效。
- **想先试试不真发**：勾选「演练模式（只打印不发送）」，照常点启动，只在日志打印「模拟发送」。
- **换电脑 / 换人用**：把整个文件夹复制过去，**先清空 `chrome_profiles/` 内容**，让对方重新登录自己的视频号；不要连登录态一起拷。

## 六、常见问题

**Q：提示「没有连上任何视频号」**
① 有没有点「启动 Chrome」；② Chrome 是否停留在视频号直播间页面；③ `accounts.json` 里端口与账号是否一一对应。

**Q：提示「找不到消息输入框」**
当前页面不在直播间，或评论框未加载。切回直播间页面再点「启动机器人」。

**Q：双击 .bat 一闪而过 / 报错**
回头检查第一步：Python 装好没？「Add Python to PATH」勾了没？

**Q：日志在哪**
`logs/日期.log`，每次发送成功 / 失败都记录。

- 仓库仅包含代码与 `config/accounts.json`（账号名、端口、话术模板，**无密码**）；`chrome_profiles/`（登录态/Cookie）已被 `.gitignore` 排除，**不会**进入版本库。

- 客户端交付时，请勿把已登录的 `chrome_profiles/` 一起打包；应让使用者在自己的电脑上首次登录。

## 十、macOS / Linux 使用

本工具同样支持 macOS 和 Linux —— `.bat` 是 Windows 专用，请用对应的 `.sh` 脚本。

**一次性准备**

```bash
bash 安装环境.sh          # 安装 Playwright（macOS 若缺系统依赖可补：python3 -m playwright install-deps）
```

> 若直接双击 `.sh` 没反应，先在终端 `cd` 到本文件夹，用 `bash 安装环境.sh` 这种方式运行；
> 想以后双击运行，可执行 `chmod +x *.sh` 一次。

**日常使用（与 Windows 两步法一致）**

```bash
bash 配置账号.sh          # 打开图形窗口：填账号/文案/端口
# 在窗口里点「启动 Chrome」登录视频号、进直播间
# 再点「启动机器人」（或另开终端执行 bash 启动机器人.sh）
```

**等价脚本一览**

| Windows | macOS / Linux | 作用 |
|---|---|---|
| 安装环境.bat | 安装环境.sh | 装 Playwright |
| 配置账号.bat | 配置账号.sh | 开配置图形窗口 |
| 启动Chrome.bat | 启动Chrome.sh | 启各账号 Chrome |
| 启动机器人.bat | 启动机器人.sh | 启动自动发言 |
| 自检.bat | 自检.sh | 无账号自检 |
| 体检.bat | 体检.sh | 真实账号体检（不发送） |

**macOS 特别注意**

- `app/chrome.py` 已内置 Mac / Chrome 路径探测；若你的 Chrome 装在非标准位置，可在 `config/accounts.json` 顶层加 `"chrome_path": "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"`。
- 若 `配置账号.sh` 报 `No module named '_tkinter'`：macOS 用 python.org 安装包自带 Tk；brew 版执行 `brew install python-tk`；Linux 执行 `sudo apt install python3-tk`。
- 登录态同样保存在 `chrome_profiles/`，**勿删**。
